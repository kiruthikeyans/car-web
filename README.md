
# 🚗 Car Web

A modern and responsive luxury car website built using HTML, Tailwind CSS, and JavaScript. This project provides a premium user experience for exploring cars, comparing models, managing wishlists, booking test drives, and more.

## ✨ Features

- 🏠 Modern Home Page
- 🚘 Car Listing
- 📄 Car Details
- ⚖️ Compare Cars
- ❤️ Wishlist
- 📅 Book Test Drive
- 📋 Booking History
- 🔔 Notifications
- 📊 Dashboard
- 🔐 Login Page
- 📱 Fully Responsive Design
- 🎨 Premium White & Red UI
- ✨ Smooth Animations
